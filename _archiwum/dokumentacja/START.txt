📋 KROK 1: INSTALACJA
═══════════════════════════════════════════════════════════════

1. Zainstaluj Python 3.8+ (jeśli nie masz):
   https://www.python.org/downloads/

2. Otwórz terminal/PowerShell w tym folderze

3. Zainstaluj zależności:

   pip install -r requirements.txt

📱 KROK 3: POŁĄCZ TELEFON
═══════════════════════════════════════════════════════════════

OPCJA A: Zeskanuj QR Code
   - Otwórz aparat w telefonie
   - Zeskanuj kod QR z ekranu
   - Kliknij link

OPCJA B: Wpisz adres ręcznie
   - Otwórz przeglądarkę w telefonie
   - Wpisz adres z ekranu (np. https://192.168.1.100:5000)
   - Zaakceptuj certyfikat ("Zaawansowane" → "Przejdź")

═══════════════════════════════════════════════════════════════
🎯 KROK 4: SKANUJ TELEFON
═══════════════════════════════════════════════════════════════

1. Kliknij "🚀 Rozpocznij Skanowanie"
2. Poczekaj 2-3 sekundy
3. System pokaże:
   - Model telefonu
   - Kod szybki (np. SA1U1)
   - Kody akcesoriów (szkło + etui)

🆘 POMOC
═══════════════════════════════════════════════════════════════

Problem: Port 5000 zajęty
Rozwiązanie: Zmień port w shark_v18.py (linia 498)

Problem: Firewall blokuje
Rozwiązanie: Dodaj wyjątek dla Python/port 5000

Problem: Telefon nie łączy się
Rozwiązanie: Upewnij się że telefon i PC są w tej samej sieci WiFi
